# Carbon Playground

An interactive website for **NCERT Class 10 Science, Chapter 4: Carbon and its Compounds**.

Each of the 16 topics has three steps:
1. **Understand it**: a short explanation in simple English
2. **Play with it**: a hands-on animation (drag, tap, slide)
3. **Check yourself**: two quick questions, with a star for each finished topic

It is a plain static site (HTML, CSS and vanilla JS, with no build step). To run it locally, use `python -m http.server` and open http://localhost:8000.
